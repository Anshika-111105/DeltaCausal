# Data Dictionary: Criteo Uplift & Synthetic Benchmark

## Criteo Uplift Prediction Dataset v2.1

The primary real dataset released by Criteo AI Lab for large-scale causal machine learning benchmarking.

| Column | Data Type | Role | Description |
|:---|:---|:---|:---|
| `f0` – `f11` | `float64` | Pre-Treatment Feature | 12 dense, anonymized continuous features representing projected user behavior, engagement, and recency. Normalized and privacy-preserving. |
| `treatment` | `int64` (0 or 1) | Treatment Indicator | `1` = User was assigned to the targeted promotional advertising campaign.<br>`0` = User was assigned to the control group (uncontacted). |
| `conversion` | `int64` (0 or 1) | Primary Outcome | `1` = User completed a purchase conversion.<br>`0` = User did not convert. |
| `visit` | `int64` (0 or 1) | Secondary Outcome | `1` = User visited the website after campaign launch.<br>`0` = User did not visit. |
| `exposure` | `int64` (0 or 1) | Treatment Adherence | `1` = User was effectively exposed to an impression.<br>`0` = User was not exposed. (In control, always 0; in treated, captures delivery adherence). |

### Dataset Characteristics:
- Total Observations: ~13,979,592 records.
- Treatment Ratio: ~85% Treated, 15% Control.
- License: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0).
- Download Source: `http://go.criteo.net/criteo-research-uplift-v2.1.csv.gz`.

## Synthetic Benchmark Dataset

Generated by `src/data/synthetic_generator.py` with known potential outcomes for exact causal evaluation.

| Column | Data Type | Role | Description |
|:---|:---|:---|:---|
| `customer_id` | `string` | Unique Identifier | Formatted as `cust_0000001`. |
| `f0` – `f11` | `float64` | Pre-Treatment Feature | Multivariate normal features with realistic cross-correlation ($\rho=0.3^{|i-j|}$). |
| `treatment` | `int64` (0 or 1) | Treatment Assignment | Randomized (85/15 ratio) or confounded via observational propensity. |
| `conversion` | `int64` (0 or 1) | Observed Outcome | SUTVA-consistent outcome: $Y = T \cdot Y(1) + (1-T) \cdot Y(0)$. |
| `visit` | `int64` (0 or 1) | Secondary Outcome | Website visit indicator correlated with conversion and treatment. |
| `exposure` | `int64` (0 or 1) | Ad Exposure | Adherence indicator (96% among treated). |
| `true_prob_y0` | `float64` | Ground Truth Probability | Latent baseline response: $P(Y(0)=1 \mid X)$. |
| `true_prob_y1` | `float64` | Ground Truth Probability | Latent treated response: $P(Y(1)=1 \mid X)$. |
| `true_y0` | `int64` (0 or 1) | Potential Outcome | Latent outcome under control: $Y(0) \sim \text{Bernoulli}(P(Y(0)=1\mid X))$. |
| `true_y1` | `int64` (0 or 1) | Potential Outcome | Latent outcome under treatment: $Y(1) \sim \text{Bernoulli}(P(Y(1)=1\mid X))$. |
| `true_cate` | `float64` | True CATE Ground Truth | $\tau^*(X) = P(Y(1)=1\mid X) - P(Y(0)=1\mid X)$. |
| `segment_label` | `string` | Causal Archetype | Ground truth category: `Persuadables`, `Sure Things`, `Lost Causes`, `Sleeping Dogs`. |
| `cost` | `float64` | Intervention Cost | Dollar cost per customer contact ($\sim \mathcal{N}(2.50, 0.20)$). |
| `margin` | `float64` | Contribution Margin | Gross profit upon conversion ($\sim \mathcal{N}(50.00, 3.00)$). |
| `expected_incremental_net_value` | `float64` | True Net Value | $\tau^*(X) \cdot \text{margin} - \text{cost}$. |
